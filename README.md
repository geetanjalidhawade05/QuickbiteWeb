# QuickbiteWeb – Online Food Ordering System

## Project Description
QuickbiteWeb is an online food ordering web application developed using ASP.NET Web Forms and C#. It allows users to register, log in, browse food items, and manage their shopping cart.

## Technologies Used
- Frontend: HTML, CSS
- Backend: C#
- Framework: ASP.NET Web Forms
- Database: SQL Server
- Database Connectivity: ADO.NET
- IDE: Visual Studio

## Features
- User Registration and Login
- Food Menu
- Browse Food Items
- Shopping Cart
- Database Connectivity
- User-Friendly Interface
